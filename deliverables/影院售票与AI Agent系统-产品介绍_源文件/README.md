# 产品介绍 PPT 源文件

这份演示文稿采用 PptxGenJS 编写，文字、流程、卡片与图形均为可编辑的 PowerPoint 元素。`pptxgenjs_helpers/` 是随项目 `slides` skill 一并保存的版式辅助代码。

## 重新生成

在本目录安装 Node.js 依赖，然后执行：

```powershell
npm install
npm run build
```

生成的文件名为 `影院售票与AI Agent系统-产品介绍.pptx`。

## 内容口径

依据项目当前 `README.md`、`docs/business-logic.md`、`docs/dify-agent-setup.md` 与前后端代码编写。第 10 页明确区分已实现能力、当前边界与可继续演进方向；支付和退款均标明为演示流程。
