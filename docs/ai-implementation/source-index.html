评估辅助代码

这些文件是开发 / 评估工具，不会因为存在就自动在生产链路执行。本文未运行它们。

  • ab_report.py：Compare pinned A/B exports; unlabelled live completion is not task accuracy.
  • build_golden.py：Freeze held-out cinema acceptance cases and preserve every clarification event.
  • eval_traces.py：Summarize exported trace directories or scored trials without external requests.
  • export_clarifications.py：Export local deidentified slot feedback without invoking a model or training it.
  • glm_smoke.py：Four synthetic public-film questions: verify GLM routing without business data.
  • golden_bindings.py：Rebind held-out fixtures privately and force paired experiments in a local CLI.
  • live_cases.py：Freeze real development data and independently declare expected query tasks.
  • loop_audit.py：Audit finite ReAct execution from recorded proposals and upstream business calls.
  • metrics.py：Independent acceptance rules and descriptive statistics for Agent evaluation.
  • phrasing_cases.py：Pair natural colloquial questions with fixed real-data gold cases.
  • phrasing_eval.py：Measure intent, facts, and tool traces on paired formal and colloquial questions.
  • report.py：Render measured results as a local, self-contained browser report.
  • rerank_focus.py：Measure evidence ranking on frozen real knowledge candidates, independently of Agent planning.
  • rerank_metrics.py：Observe real reranking decisions, provider usage and fallback without changing ranking.
  • rescore_phrasing.py：Apply transparent scoring corrections to an already completed phrasing run.
  • review.py：Apply explicit human adjudications while retaining all original automatic scores.
  • routing_audit.py：Audit cheap routing against frozen gold plans without querying any provider.
  • run.py：Compare real Qwen calls on current/previous workflows and real development queries.
  • runtime_check.py：Inspect termination of the already running Agent using frozen real query cases.
  • train_intent_classifier.py：Train a local nine-intent classifier with scenario-isolated validation and test sets.
  • verify_snapshot.py：Check that the live business facts still match the frozen scoring snapshot.
  • workflow_cases.py：Freeze 72 query scenarios, each with a standard and a conversational expression.
  • workflow_eval.py：Run 144 frozen real questions twice against the current workflow.
