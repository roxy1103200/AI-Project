# 影院 Agent 口语化问题评测

## 评测范围

2026-10-10 在隔离评测进程中直接调用当前源码的 `Assistant.live`，后端读取开发环境实时影片、场次、座位及测试账户数据；Qwen 3.7 Flash 与 Rerank 均已开启。计时不包含网关、登录和浏览器。共运行 72 道问题：24 道标准表达、每题两种口语改写。每道题运行一次，串行执行，记忆关闭；业务调用预算为每任务 4 次。

题集里有一条口语题写成“这片还有能下单的场次吗”，但它没有影片名称，历史对话也没有前文指代。为避免把信息缺失误算成 Agent 失败，主结果将其剔除，最终比较 24 道标准题与 47 道口语题。评分还修正了两处口径：接受明确要求的纯数字座位答案；把 Markdown 中的座位数字纳入事实检查。直接购票/支付问题的期望意图标为“不支持的操作”。另将“还在放”答成全片库标记为事实不符合问题范围。

## 结果

- 整题成功率：56/71，78.9%。成功要求工具名称、参数、调用顺序、答案关键事实和完整结束都通过。
- 答案关键事实通过率：61/71，85.9%。这是固定答案检查并经过上述人工口径复核，不等同于完整语义评审。
- 意图识别准确率：61/71，85.9%。按首个 Agent 上下文中的意图与人工标注比较。
- 严格工具链正确率：56/71，78.9%。按冻结的预期工具及参数计划逐题核对。
- 首字耗时 P50/P95：3.24 秒 / 4.90 秒；完整回答耗时 P50/P95：3.35 秒 / 6.48 秒。
- 平均模型调用：2.27 次/题；估算总费用约 ¥0.0554（按留存公开单价与实际 Token/缓存用量估算，不是账单金额）。

费用估算使用北京区域、输入不超过 32K 的 Qwen 3.7 Flash 原价：输入 ¥0.2/百万 Token、输出 ¥0.8/百万 Token、缓存命中输入 ¥0.04/百万 Token；[阿里云模型价格说明](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)。

标准题 24/24 整题成功；口语题 32/47，68.1%。口语题关键事实通过率为 37/47，78.7%；意图识别为 38/47，80.9%；严格工具链正确率为 32/47，68.1%。这个差距主要集中在座位查询和复合任务。

分组看，澄清任务 12/12 成功，普通查询 28/35，组合任务 11/18，安全边界 5/6。订单查询 12/12、退票查询 9/9；座位任务仅 9/18 全部成功。

## 工具链与结束情况

纳入主结果的 71 题实际执行 68 次业务工具调用：影片查询 13 次、场次查询 18 次、座位查询 8 次、订单查询 18 次、退票政策查询 8 次、推荐 3 次。59 道需要业务查询的题平均执行 1.15 次工具调用。共记录 69 个工具提案，其中 1 个被参数校验拒绝；相同工具和参数的重复执行为 0 次；单任务最多执行 3 次业务调用。所有 72 条流都正常结束，没有超时或无限循环。

运行能结束，但部分复合问题在只完成一项后就生成最终答复。例如“查最低票价并顺便问退票期限”有口语变体只查了其中一项；有的“先查电影，再查排期和座位”只执行电影查询。属于漏项或提前完成，不是循环不退出。

## 主要错例

- **口语场次编号未提取**：四种口语表达用“38 这场”“38 号场”“38 场”等说法询问座位。Agent 都识别为座位意图，但 `screening_id` 为空，最终追问场次编号，未调用座位工具。标准格式“场次 38”则能通过。
- **多步骤任务不稳定**：18 道组合题中 7 道没有按计划完成。常见情况是查询了排期却未继续查空座，或只处理了退票规则而漏掉票价。
- **安全意图存在一例偏移**：一条“直接帮我下单再付款”的口语请求被识别成场次查询并返回场次，另一种近似表达则正确拒绝购票/支付。没有发生下单或支付写操作。
- **范围参数冲突**：一条“现在还有哪几部电影在放”的口语题，模型先提出 `showing` 范围但被子任务参数校验拒绝，随后改为 `catalog` 查询并返回过期影片。校验阻止了错误参数直接执行，但重试结果仍未满足用户范围。

## 结果解释

这是一轮单次题集回放，不是线上 SLA，也不是多次抽样后的稳定成功率。口语题和标准题使用相同的实时业务快照，但个别题目由文字改写导致了缺少指代；已在主结果中剔除该题。严格工具链率依赖冻结的预期计划；事实率依赖题目关键检查项。报告保留原始 72 题追踪，并另存修正后的评分结果，所有修正均未重复调用模型。

原始轨迹与汇总位于 `cinema-ticketing-backend/target/agent-evaluation/colloquial-results-20261010/`；复评分脚本为 `cinema-ticketing-backend/cinema-ai/evaluation/rescore_phrasing.py`，下一轮题集生成脚本为 `cinema-ticketing-backend/cinema-ai/evaluation/phrasing_cases.py`。
